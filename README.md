# ✨ Happy Birthday — Interactive Experience

A premium, responsive birthday microsite built with pure **HTML, CSS and JavaScript**.

## Features
- Cinematic glassmorphism design
- Animated aurora background and particles
- Scroll reveal animations
- Interactive birthday cake and candle
- Wish-making interaction
- Confetti celebration effects
- Toast notifications
- Responsive mobile-first layout
- No framework or build step required

## Run
Open `index.html` in any modern browser.

## Files
- `index.html` — page structure and content
- `style.css` — visual design, responsive layout and animations
- `script.js` — particles, interactions, confetti and effects
